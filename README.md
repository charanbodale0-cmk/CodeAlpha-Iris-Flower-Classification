# Iris Flower Classification 🌸

This project classifies Iris flowers into different species using Machine Learning.

## Dataset
The project uses the Iris dataset.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Machine Learning
The model is trained to classify Iris flowers based on their:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Project File
`CodeAlpha_Iris_Flower_Classification.ipynb`
